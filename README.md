# FUTURE_CS_03

# Task 3 – API Security Risk Analysis

## Objective
To analyze API security and identify risks.

## API Used
https://jsonplaceholder.typicode.com

## Issues Found

1. No Authentication (High)
Anyone can access data without login.

2. Data Exposure (Medium)
User details like email are visible.

3. No Rate Limiting (Medium)
API allows unlimited requests.

4. No Input Validation (Low)
API does not check input properly.

## Conclusion
The API has security risks and needs protection.
